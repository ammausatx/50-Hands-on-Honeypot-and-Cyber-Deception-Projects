# 50 Hands-on Honeypot and Cyber Deception Projects

A practical, defensive learning collection covering honeypot design, deployment, monitoring, attacker-interaction analysis, and cyber deception engineering.

> **Lab safety:** Build and test only in systems and networks you own or are explicitly authorized to assess. Keep high-interaction honeypots isolated from production networks, deny unnecessary outbound access, use synthetic data only, and forward logs through a controlled path.

Project guides and the complete index are being added.
