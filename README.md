## Lab safety principles

- Work only on systems and networks you own or are explicitly authorized to assess.
- Isolate honeypots from production networks; apply deny-by-default egress and prevent pivoting.
- Use synthetic identities, credentials, files, and data. Avoid collecting real passwords or personal information.
- Treat captured files and malware as untrusted. Analyze only in a separate, disposable sandbox.
- Preserve logs, synchronize clocks, redact sensitive evidence, and document containment and rebuild procedures.
- Never retaliate or access third-party systems observed in honeypot telemetry.

## Project format

Each project includes an objective, scope and safety notes, prerequisites, lab design, step-by-step procedure, expected observations, analysis guidance, validation and retest steps, deliverables, and a screenshot checklist.

Each folder also contains three **simulated SVG training illustrations** (workflow, findings, validation). These are diagrams—not real screenshots, captured traffic, or proof of execution. Add your own genuine, redacted lab screenshots to document your work.
